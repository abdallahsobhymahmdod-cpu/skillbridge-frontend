# SkillBridge Frontend

A complete React + Vite frontend for SkillBridge, ready to connect to a backend API.

## Run

```bash
npm install
npm run dev
```

Open: http://localhost:3000

## API Mode

Copy `.env.example` to `.env`.

```env
VITE_API_BASE_URL=http://localhost:5000/api
VITE_USE_DUMMY_DATA=true
```

Set `VITE_USE_DUMMY_DATA=false` when your backend is ready.

## Demo Login

- User: `user@skillbridge.com`
- Admin: `admin@skillbridge.com`
- Any password works in dummy mode.
